# Engine sample projects

Each folder is a minimal host project with assets exported by the MCP server. The source art is in `source/` (`hero.aseprite`, a 4-tag character, and `level.aseprite`, a tilemap).

Rebuild everything (needs Aseprite):

```bash
npm run build
npx tsx examples/build-samples.ts
```

The script runs workflows 2, 3 and 5 from [`../workflows.ts`](../workflows.ts) with this folder as the workspace root, then checks every output with `engine.validate`.

| Folder | Engine | How to run | Generated by |
|---|---|---|---|
| `godot/` | Godot 4.4+ | open `project.godot`, run `main.tscn` | `engine.godot_sample_scene`, `engine.godot_tilemap_scene` |
| `unity/` | Unity 6000.6 | open the folder in Unity Hub | `engine.unity_aseprite`, `engine.unity_sheet`, `engine.unity_package` |
| `phaser/` | Phaser 3.90 | serve the folder over HTTP, open `index.html` | `engine.phaser` |
| `pixi/` | PixiJS 8 | serve the folder over HTTP, open `index.html` | `engine.pixi` |
| `love/` | LÖVE 11 | `love examples/engines/love` | `engine.love` |
| `pygame/` | Pygame 2 | `python examples/engines/pygame/main.py` | `engine.pygame` |
| `defold/` | Defold | open `game.project` | `engine.defold` |
| `gamemaker/` | GameMaker | manual import, see its README | `engine.gamemaker` |
| `cocos/` | Cocos Creator / 2d-x | manual import, see its README | `engine.cocos` |

The output formats have been checked by structure only. They have not been opened in each engine. See [docs/compatibility.md](../../docs/compatibility.md) for what was verified.
