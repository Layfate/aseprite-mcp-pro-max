## Legacy profile (v1-compatible names)

`ASEPRITE_MCP_PROFILE=legacy` — 13 tools.

### aseprite_status

Report the Aseprite executable/version, workspace roots, live-editor bridge state and optional features.

### aseprite_create

Create a new .aseprite file with an optional palette preset, layers and tagged animations.

### aseprite_inspect

Read sprite metadata: size, color mode, layers, frames, tags, slices and palette.

### aseprite_edit

Apply a batch of v1 edit operations in one atomic transaction (v1 op names, e.g. pixel_map, rect, add_layer).

### aseprite_read_pixels

Read pixels as a character grid with a color legend (pixel_map format).

### aseprite_preview

Render frames as a scaled-up PNG image (nearest-neighbour, checkerboard).

### aseprite_compare

Diff two frames (or the same frame in another sprite) with an A | B | diff image.

### aseprite_validate

Lint pixel art and animation (check.lint); paths validates several files.

### aseprite_export

Export PNG, GIF or sheet + JSON; presets: godot (SpriteFrames .tres), unity, phaser, generic.

### aseprite_import_image

Turn a PNG/JPG into clean pixel art: new sprite (path) or new layer (into).

### aseprite_palette

Palette helpers: list, get, ramp, extract.

### aseprite_history

Checkpoints: list, undo (steps), redo, restore (id). Live mode: editor undo/redo.

### aseprite_live

Live editor: status, install_extension, list_open, open, save.
